# Linear Regression Machine Learning Models

This repository contains machine learning models and datasets for performing linear regression.

## Contents
- **linear regression with single variable.ipynb**: Jupyter notebook demonstrating simple linear regression with one variable.
- **linear regression with multiple variables.ipynb**: Jupyter notebook demonstrating multiple linear regression.
- **Datasets**: Various CSV files (`hiring.csv`, `canada_per_capita_income.csv`, `info.csv`, etc.) used for training and testing the models.
