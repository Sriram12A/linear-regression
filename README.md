# Linear Regression Models

This repository contains machine learning projects focused on Linear Regression. It demonstrates the implementation of both single-variable and multi-variable linear regression models using Python.

## Project Structure

- `linear regression with single variable.ipynb`: Jupyter Notebook demonstrating simple linear regression with a single feature (e.g., predicting income or prices based on one variable).
- `linear regression with multiple variables.ipynb`: Jupyter Notebook demonstrating multiple linear regression using multiple features (e.g., predicting salaries based on experience, test scores, and interview scores).
- **Datasets**: Various CSV files used to train and test the models (`canada_per_capita_income.csv`, `hiring.csv`, `info.csv`, `multi.csv`, etc.).

## Technologies Used
- **Python 3.x**
- **Pandas** (Data manipulation)
- **NumPy** (Numerical operations)
- **Scikit-Learn** (Machine Learning models)
- **Matplotlib** (Data visualization)
- **Jupyter Notebook** (Interactive development)

## Setup and Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/Sriram12A/linear-regression.git
   cd linear-regression
   ```

2. Create a virtual environment (optional but recommended):
   ```bash
   python -m venv venv
   # On Windows use: venv\Scripts\activate
   # On macOS/Linux use: source venv/bin/activate
   ```

3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Start Jupyter Notebook to view and run the projects:
   ```bash
   jupyter notebook
   ```
