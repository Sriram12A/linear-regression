# Simple Linear Regression

This folder contains the implementation and datasets for predicting a target variable using a single independent variable (Simple Linear Regression).

### Contents
- **`linear regression with single variable.ipynb`**: A Jupyter Notebook detailing the mathematical intuition and Python code to train a simple linear regression model.
- **`canada_per_capita_income.csv`**: A dataset containing historical data of Canada's per capita income. The model predicts future income based on the year.
- **Other CSVs**: Additional testing and information files for experiments.
