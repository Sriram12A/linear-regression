# Multiple Linear Regression

This folder contains the implementation and datasets for predicting a target variable using two or more independent variables (Multiple Linear Regression).

### Contents
- **`linear regression with multiple variables.ipynb`**: A Jupyter Notebook detailing how to train a model with multiple features, including data preprocessing techniques such as handling missing values.
- **`hiring.csv`**: A dataset containing candidate experience, written test scores, and personal interview scores used to predict the salary they should be offered.
- **Other CSVs**: Additional testing and information files for experiments.
